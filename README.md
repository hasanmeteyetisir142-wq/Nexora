# Nexora

Nexora is a dark, responsive social gaming platform for discovering games, connecting gaming identities, and finding friends.

## Stack
- Next.js 15 / React 19
- TypeScript
- Lucide icons

## Development
```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Current status
The first UI foundation is in place. Account tiles are presentation-only; official OAuth/API integrations, authentication, database-backed profiles, messaging, and community features are not yet connected. Never enter gaming account passwords into Nexora.
